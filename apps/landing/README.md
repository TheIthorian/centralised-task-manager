# @ctm/landing

Astro landing / marketing page. Statically generated. Deployed independently from the main app.

## Sections

- Hero
- Features
- How It Works
- Integrations
- Footer CTA

## Stack

- Astro
- Tailwind CSS
- React (islands for interactive components)

## Commands

```bash
pnpm --filter @ctm/landing dev      # Astro dev server
pnpm --filter @ctm/landing build    # static build → dist/
pnpm --filter @ctm/landing preview  # preview production build
```
